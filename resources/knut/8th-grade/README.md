# Årskurs 8: Lgr22 2026

Det finns ingen separat nationell "skolplan 2026" för årskurs 8. För svensk grundskola gäller Skolverkets **Lgr22** och ämnenas kursplaner. Kursplanerna anger centralt innehåll för stadiet eller intervallet 7–9, inte ett separat målpaket för årskurs 8. Betygskriterierna gäller i slutet av årskurs 9.
